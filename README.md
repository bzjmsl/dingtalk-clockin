# 钉钉打卡助手（Windows / ADB）

一个跑在 Windows 上的小工具：在工作日的设定时间窗口内随机取一个时刻，通过 ADB 唤醒并解锁手机、打开钉钉，由钉钉「极速打卡」完成打卡；也可以切换成直接点击打卡按钮的模式。

> 仅供个人设备上的自动化实验。自动打卡可能违反用人单位的考勤制度，使用前请自行确认合规性，风险自负。

## 功能

- **工作日判定**：手动条目 → 联网接口缓存 → 周一至周五；支持法定节假日与调休补班
- **时间窗口随机**：每天在窗口内取一个固定的随机时刻，重启程序不变
- **两种模式**
  - 极速打卡：只负责唤醒、解锁、打开钉钉，打卡由钉钉完成，不碰任何按钮
  - 手动点击：进入打卡页点按钮，自动识别内勤（蓝色）与外勤（绿色），遇到外勤可中止
- **图形界面**：概览、打卡设置、节假日、日志与截图；深浅两套主题；托盘常驻、可选开机自启
- **截图可关**：设置里关闭后不再写入 `data\shots\`；手动模式判断内勤/外勤用的临时截图用完即删
- **截图可删**：日志页可删除单张或一键清空，同步删除磁盘文件与界面引用
- **打卡前自检**：没有网络、或连着 WiFi 但无法访问外网时中止并说明原因；定位未开启只提示（实测不影响极速打卡）
- **通知可关**：设置里关闭后不再弹托盘气泡，日志与截图照常记录
- **免安装**：编译产物是单个 exe，只依赖系统自带的 .NET Framework 4.8

## 环境要求

- Windows 10 / 11（自带 .NET Framework 4.8）
- Android 手机，已开启「开发者选项 → USB 调试」并授权本机
- platform-tools（adb），可用 Android SDK 自带，也可单独下载
- 钉钉已登录；使用极速打卡模式时，需在钉钉里开启「极速打卡」

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File app\build.ps1
```

产物在 `app\dist\DingTalkClockIn.exe`。不需要 Visual Studio 或 .NET SDK，构建脚本直接调用系统自带的 `csc.exe`，XAML 作为嵌入资源在运行时加载。

版本号默认取最近的 git tag（`v1.0.2` → `1.0.2`），也可以显式指定：`.\app\build.ps1 -Version 1.0.3`，界面左下角显示的就是这个版本。

命令行版本保留在 `dingtalk-clockin.ps1`，用法见文件头部注释。

## 使用

1. 双击 `DingTalkClockIn.exe`
2. 打开「打卡设置」：填写锁屏密码、确认 adb 路径，点「测试连接」
3. 设定上下班时间窗口与打卡模式，点「保存设置」
4. 需要开机自动运行就勾选「开机自动启动」
5. 概览页可以看到下次执行时间与倒计时，「立即试跑」是干跑，不会真正点击

密码使用 Windows DPAPI 加密后保存，只有当前 Windows 用户能解密。

## 数据目录

运行数据保存在 exe 同级的 `data\`：

| 文件 | 说明 |
| --- | --- |
| `config.json` | 配置，含加密后的锁屏密码 |
| `holidays.json` | 手动维护的节假日与调休 |
| `state.json` | 每天每档的执行记录与最近一次结果 |
| `logs\` | 每日运行日志 |
| `shots\` | 打卡页与结果截图 |

`data\` 里还包含 ADB 私钥备份（`adbkey.backup`）和带有个人信息的截图，**已被 `.gitignore` 排除，请勿提交**。

截图可以在「日志与截图」页删除单张或清空全部；如果不想留下截图，在「打卡设置 → 行为选项」里关掉「保存打卡截图」即可。

## 适配说明

打卡按钮、首页入口、锁屏键盘的坐标基于 1080×1920 的机型实测，写在 `config.json` 的 `advanced` 段。更换手机、修改系统分辨率或钉钉大版本更新后，需要重新测量这些坐标。

## 已知限制

- 依赖手机 USB 连接与 adb；手机拔线或未授权时无法执行
- 极速打卡模式依赖钉钉自身的识别逻辑，触发时机由钉钉决定
- 打卡页是小程序（webview）渲染，只能通过固定坐标与截图颜色判断，无法读取页面文字
- 电脑在触发时刻必须开机
